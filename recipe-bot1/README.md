# recipe-bot1

Telegram-бот-анкета со встроенной базой данных **SQLite3** и экспортом данных в **Excel**.

## Возможности

Меню бота (вызывается командой `/start`):

1. **Ваше имя** — ввод имени
2. **Фамилия** — ввод фамилии
3. **Год рождения** — ввод года рождения
4. **Месяц рождения** — выбор месяца (кнопки)
5. **Увлечения или работа** — ввод увлечений/работы
6. **Выгрузить в Excel** — выгрузка всех анкет в Excel-файл

## Формат хранения данных

Выбран формат: **встроенная база данных SQLite3** (файл `database.db` в корне проекта).

SQLite3 — встроенная реляционная БД, не требует сервера, хранится одним файлом, поддерживает SQL. Данные также выгружаются в **Excel** пунктом меню "Выгрузить в Excel" (файлы появляются в папке `exports/`).

### Таблица базы данных

| Таблица | Назначение | Поля |
|---|---|---|
| `users` | Анкетные данные пользователей | `id`, `user_id`, `first_name`, `last_name`, `birth_year`, `birth_month`, `hobbies`, `created_at`, `updated_at` |

Строка `user_id` уникальна — у каждого пользователя Telegram хранится одна анкета, данные обновляются при повторном вводе.

## Установка и запуск

```bash
pip install -r requirements.txt
python bot.py
```

Перед запуском создайте файл `.env`:

```
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
```

## Структура проекта

```
recipe-bot1/
├── bot.py            # основной код бота, меню, обработчики
├── db.py             # работа с SQLite3 (таблица users)
├── keyboards.py      # инлайн-клавиатуры (меню, месяцы)
├── excel_export.py   # экспорт анкет в Excel (openpyxl)
├── requirements.txt  # зависимости
├── .env              # токен бота (не коммитится)
└── database.db       # база данных SQLite3 (создаётся автоматически)
```
