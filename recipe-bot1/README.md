# recipe-bot1

Telegram-бот-анкета со встроенной базой данных **SQLite3** и экспортом данных в **Excel**.

## Возможности

Меню бота (вызывается командой `/start`):

1. **Ваше имя** — ввод имени
2. **Фамилия** — ввод фамилии
3. **Год рождения** — ввод года рождения
4. **Месяц рождения** — выбор месяца (кнопки)
5. **Увлечения или работа** — ввод увлечений/работы
6. **Выгрузить в Excel** — выгрузка всех анкет в Excel-файл

## Формат хранения данных

Выбран формат: **встроенная база данных SQLite3** (файл `database.db` в корне проекта).

SQLite3 — встроенная реляционная БД, не требует сервера, хранится одним файлом, поддерживает SQL. Данные также выгружаются в **Excel** пунктом меню "Выгрузить в Excel" (файлы появляются в папке `exports/`).

### Таблица базы данных

| Таблица | Назначение | Поля |
|---|---|---|
| `users` | Анкетные данные пользователей | `id`, `user_id`, `first_name`, `last_name`, `birth_year`, `birth_month`, `hobbies`, `created_at`, `updated_at` |

Строка `user_id` уникальна — у каждого пользователя Telegram хранится одна анкета, данные обновляются при повторном вводе.

## Установка и запуск

```bash
pip install -r requirements.txt
python bot.py
```

Перед запуском создайте файл `.env`:

```
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
```

## Структура проекта

```
recipe-bot1/
├── bot.py            # основной код бота, меню, обработчики
├── db.py             # работа с SQLite3 (таблица users)
├── keyboards.py      # инлайн-клавиатуры (меню, месяцы, валюты)
├── currency.py       # курсы валют (open.er-api.com) и конвертация
├── excel_export.py   # экспорт анкет в Excel (openpyxl)
├── requirements.txt  # зависимости
├── .env              # токен бота (не коммитится)
├── database.db       # база данных SQLite3 (создаётся автоматически)
└── render.yaml       # конфиг для деплоя на Render.com
```

## Запуск на Render.com (работает 24/7 без вашего ПК)

Бот запускается через **webhook** (Render не «засыпает»). Адрес вебхука берётся из `RENDER_EXTERNAL_URL` автоматически — вручную настраивать ничего не нужно.

1. Запушьте код в GitHub.
2. Зайдите на [dashboard.render.com](https://dashboard.render.com) → **New** → **Blueprint** → укажите репозиторий.
3. Render найдёт `render.yaml` и спросит `TELEGRAM_BOT_TOKEN` — токен от BotFather.
4. Дождитесь деплоя и напишите боту `/start`.

Альтернатива: вручную создать **New → Web Service**, выбрать папку `recipe-bot1`:
- Build Command: `pip install -r requirements.txt`
- Start Command: `python bot.py`
- Env var: `TELEGRAM_BOT_TOKEN`.

> ⚠️ Важно: на Render файловая система непостоянная — `database.db` сбрасывается при каждом деплое. Если нужна постоянная база анкет, потребуется внешняя БД (например, Supabase). Курсы валют работают без БД.
